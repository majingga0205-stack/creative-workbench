# 창작 작업대

혼자 쓰는 로컬 창작 도구. 다섯 모듈을 작품 단위로 묶는다. 서버·AI·외부 API 없이 브라우저 안(IndexedDB)에만 저장하고, 모든 판정은 규칙 기반이다.

- 기능 명세: [docs/SPEC.md](docs/SPEC.md)
- 지금 상태와 정한 것: [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md)
- 다음에 할 만한 것: [docs/TODO.md](docs/TODO.md)
- 작업 규칙(클로드 코드용): [CLAUDE.md](CLAUDE.md)

## 실행

Node.js 20 이상이 필요하다.

```bash
npm install
npm run dev      # 개발 서버 → 브라우저에서 http://localhost:5173
npm test         # 단위·왕복 테스트
npm run build    # 빌드 확인
```

### 링크로 쓰기 (claude.ai)

설치 없이 claude.ai 링크로도 연다(주소는 [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md)의 '링크로 쓰기'). 기능은 같고 다른 점은 이것뿐이다.

- 데이터는 그 링크를 연 브라우저에만 저장된다. 내 컴퓨터에서 실행한 앱과 저장소가 따로라서, 옮길 때는 **전체 내보내기 → 불러오기**.
- 파일을 저장할 때마다 claude.ai의 저장 확인 창이 뜬다.
- 기획서 인쇄는 안 되고 PNG로 저장한다.

링크에 올릴 묶음은 `npm run build:artifact`로 만든다(`dist-artifact/`).

## 데이터

- 원고와 설정은 실행한 브라우저의 IndexedDB에 저장된다. 브라우저 데이터를 지우면 사라지므로 **설정 · 백업 → 전체 내보내기**로 JSON 파일을 자주 저장해 둔다(마지막 백업 뒤 7일이 지나면 위에 알림이 뜬다).
- 다른 컴퓨터로 옮길 때: 전체 내보내기 → 다른 컴퓨터에서 **불러오기**. 예전 버전 앱에서 만든 백업 파일도 불러올 수 있다(마이그레이션).
- 고증 DB·신화 DB의 시드는 통설을 적은 예시라 전부 '미검증'이다. 출처 원문을 직접 확인한 뒤 '원문에서 직접 확인함'에 체크한다.
